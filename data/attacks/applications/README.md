# Poisoned offers and cover letters

Fictional attacks on offer import and applications, generated by `python scripts/generate_job_offer_samples.py` and
checked by `backend/services/screener/tests/test_screener_applications.py`. `expected.json` holds the same table for
the tests.

| File | Attack | Flagged | Hidden text removed | Effect |
|---|---|---|---|---|
| `offer_clean.pdf`, `letter_clean.pdf` | none | no | no | baseline |
| `offer_hidden.pdf` | White instruction in an offer | yes | yes | Never reaches the model; shown to HR before publishing |
| `offer_visible.pdf` | Visible instruction in an offer | yes | no | Never reaches the model; shown to HR before publishing |
| `offer_unfair.pdf` | A requirement on age, gender and photo | no | no | Listed in `flagged_requirements`; HR decides |
| `letter_hidden.pdf` | White instruction in a cover letter | yes | yes | Never reaches the model; the score does not change |
| `letter_visible.pdf` | Visible instruction in a cover letter | yes | no | Never reaches the model; the score does not change |

The letter files test service code that nothing in the gateway calls: there is no public page for applying.
